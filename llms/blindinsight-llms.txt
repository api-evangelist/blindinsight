# Blind Insight

> Blind Insight is an end-to-end encrypted datastore and privacy-preserving data-analysis platform. Teams encrypt, ingest, search, and run machine learning and LLM queries over fully encrypted records without exposing plaintext, using a locally deployed Blind Proxy that performs client-side encryption/decryption against the cloud REST API.
